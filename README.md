# QVAC projects

The hub page for five open-source projects built on [Tether QVAC](https://docs.qvac.tether.io/): **https://qvac.lopeselio.online**

| Project | What it is | Hosted |
|---|---|---|
| [qvac-wallet-guardian](https://github.com/lopeselio/qvac-wallet-guardian) | Explains EVM transactions and signatures before you sign: rules-first scam detection, a guarded local QVAC LLM explanation, and a guard for Tether WDK accounts. | [wallet-guardian.qvac.lopeselio.online](https://wallet-guardian.qvac.lopeselio.online), runs in the browser |
| [qvac-ci-doctor](https://github.com/lopeselio/qvac-ci-doctor) | Finds why CI failed: the first real error, real failure or flaky, and the exact log lines. A local QVAC model explains it, and is only shown if its answer passes checks. | [ci-doctor.qvac.lopeselio.online](https://ci-doctor.qvac.lopeselio.online), runs in the browser |
| [qvac-pocket-tune](https://github.com/lopeselio/qvac-pocket-tune) | Teach a small model your voice from notes, chats or spoken answers: scrubbed, fine-tuned on your own computer or phone, compared, and shared peer-to-peer. | [pocket-tune.qvac.lopeselio.online](https://pocket-tune.qvac.lopeselio.online), project page (runs on your device) |
| [qvac-babel-room](https://github.com/lopeselio/qvac-babel-room) | Live captions across languages with no server: Whisper and Bergamot on each device, rooms over Hyperswarm, on phones, laptops and terminals. | [babel-room.qvac.lopeselio.online](https://babel-room.qvac.lopeselio.online), project page (runs on your device) |
| [qvac-seed](https://github.com/lopeselio/qvac-seed) | Share local AI models and LoRA adapters as pear:// links the QVAC SDK loads directly: seeded over Hyperswarm, verified by SHA-256. | [seed.qvac.lopeselio.online](https://seed.qvac.lopeselio.online), project page (runs on your device) |

`site/` is published to GitHub Pages by `.github/workflows/pages.yml`.
